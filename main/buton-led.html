Arduino uno Buton ile Led Yakma

Alptuğra'nın Arduino Rehberi

Buton ile Led yakma

Malzemeler:

Arduino Uno
Led
Breadboard
220 Ω direnç
erkek-erkek jumper kaplo
Button
10kΩ direnç

Devre kurulumu

Kod:

#define Buton 13
#define Led 9
void setup()
{
pinMode(Buton, INPUT);
pinMode(Led, OUTPUT);
}
void loop()
{
if (digitalRead(Buton) == 1)
digitalWrite(Led,HIGH);
else
digitalWrite(Led,LOW);
}
